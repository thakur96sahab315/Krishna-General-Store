# Krishna General Store Website

A responsive front-end shop website built with HTML, CSS and JavaScript.

## Run in VS Code
1. Extract `Krishna_General_Store_Website.zip`.
2. Open the extracted folder in VS Code.
3. Open `index.html` in your browser, or install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.

## Important: personalise before publishing
- Store WhatsApp contacts are configured as 9569654740 and 9580835257. The order flow asks which number to message.
- Edit the `products` array in `script.js` to add your real product names, prices, descriptions and image links. The listed prices are placeholders/demo values.
- Prices and stock in this starter website are sample/demo values. Confirm actual prices and availability with the shop before accepting orders.
- Replace the sample product photos with photos of your actual shop products for best results.

## Features
- Responsive layout for desktop and mobile
- Cosmetics, skincare, bangles, accessories, grocery, household, pooja, wedding decoration and stationery categories
- Product search and category filters
- Add-to-cart, quantity controls, remove item and subtotal
- WhatsApp order message (works after adding the shop number)
- Product catalogue is easy to edit in `script.js`

## Technology
HTML5, CSS3, Vanilla JavaScript. This is a front-end starter project; it does not yet include a database, admin login, payment gateway or online inventory management.
